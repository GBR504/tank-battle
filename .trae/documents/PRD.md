## 1. 产品概述
经典坦克大战（Battle City / 坦克1990）网页复刻版，使用 HTML5 Canvas 单文件实现，让玩家在浏览器中即开即玩，重温红白机时代的策略射击乐趣。
- 主要目的：提供一个零依赖、可离线运行、易分享的经典像素坦克游戏
- 目标用户：怀旧游戏爱好者、休闲玩家、想体验经典 FC 玩法的网页用户

## 2. 核心功能

### 2.1 用户角色
无角色区分，单人本地游戏（玩家 vs AI）。

### 2.2 功能模块
1. **开始界面**：游戏标题、操作说明、开始按钮、关卡选择
2. **游戏界面**：战场地图、玩家坦克、敌方坦克、子弹、墙体、基地、HUD（生命/得分/关卡/剩余敌机）
3. **结算界面**：胜利/失败提示、得分统计、重新开始/返回菜单

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 开始界面 | 标题区 | 复古像素 LOGO 动画、副标题、版本信息 |
| 开始界面 | 操作说明 | 方向键/WASD 移动、空格射击、规则简介 |
| 开始界面 | 开始按钮 | 点击进入第 1 关，支持选关 |
| 游戏界面 | 战场地图 | 13×13 网格 Canvas 渲染，含砖墙/钢墙/水/草丛/基地 |
| 游戏界面 | 玩家坦克 | 4 方向移动、单发射击、复活无敌、3 条命 |
| 游戏界面 | 敌方坦克 | AI 寻路/随机移动、4 种类型（速度/装甲/普通/快速）、刷怪点 |
| 游戏界面 | HUD | 生命、得分、关卡、剩余敌机数、暂停按钮 |
| 游戏界面 | 暂停 | P 键暂停，遮罩+提示 |
| 结算界面 | 胜利 | 通关祝贺、总分、下一关/重玩 |
| 结算界面 | 失败 | 基地被毁/生命耗尽、得分、重玩/返回菜单 |

## 3. 核心流程

玩家从开始界面进入游戏，控制坦克在地图上移动并射击敌方坦克与可破坏砖墙，保护己方基地（鹰标）不被摧毁。消灭本关全部敌方坦克即通关进入下一关；玩家生命耗尽或基地被毁则游戏失败。

## 4. 用户界面设计

### 4.1 设计风格
- 主色：FC 经典黑底 (#000) + 军绿 (#6b8e23) + 沙黄 (#d9b382)；玩家坦克黄 (#ffcc00)，敌方坦克灰/绿/红
- 像素风：所有元素以 16×16 像素块为单位，关闭抗锯齿（image-rendering: pixelated）
- 字体：Press Start 2P（像素显示字体）+ 中文回退
- 布局：居中固定 416×416 战场（13 格×32px）+ 右侧 96px 信息栏，整体 512×416
- 按钮风格：像素描边方块按钮，hover 位移 1px

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 开始界面 | 标题 | 闪烁像素 LOGO、扫描线滤镜、动态星空背景 |
| 游戏界面 | 战场 | 网格地图、像素坦克、爆炸粒子、子弹轨迹 |
| 游戏界面 | 信息栏 | 关卡数、生命图标、敌机图标列表、暂停提示 |
| 结算界面 | 弹窗 | 半透明遮罩、像素边框、得分大字、按钮 |

### 4.3 响应式
- 桌面优先：固定 512×416 画布，居中显示
- 移动端自适应：Canvas 等比缩放至视口，提供虚拟方向键 + 射击按钮（触摸设备）
- 触摸优化：虚拟摇杆位于左下，射击按钮位于右下，半透明大尺寸

### 4.4 3D 场景
不适用（2D 像素游戏）。
