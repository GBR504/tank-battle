# 坦克大战 · Battle City

经典红白机坦克大战（Battle City / 坦克1990）的网页复刻版，使用纯 HTML5 Canvas 单文件实现，零依赖，开箱即玩。

![Battle City](https://img.shields.io/badge/genre-Arcade-red) ![HTML5](https://img.shields.io/badge/HTML5-Canvas-orange) ![single file](https://img.shields.io/badge/build-single%20file-brightgreen)

## 玩法

控制黄色坦克在战场中移动并射击敌方坦克，保护底部的鹰巢基地不被摧毁。消灭本关全部 20 辆敌方坦克即可通关，共 4 个关卡。

### 操作

| 操作 | 键盘 | 触屏 |
|------|------|------|
| 移动 | 方向键 / WASD | 左下虚拟方向键 |
| 射击 | 空格 / J | 右下 FIRE 按钮 |
| 暂停 | P | P |

### 元素

- **砖墙**（橙）：可被子弹逐块破坏
- **钢墙**（灰）：坚固不可破坏（玩家升至 3 级可击穿）
- **水域**（蓝）：坦克不可通过，子弹可穿过
- **草丛**（绿）：坦克可隐蔽，渲染于顶层
- **鹰巢基地**（金）：被毁则游戏结束

### 敌方坦克

| 类型 | 颜色 | 特点 | 分值 |
|------|------|------|------|
| 普通 | 灰 | 速度慢 | 100 |
| 快速 | 白 | 移动快 | 200 |
| 强力 | 绿 | 子弹快 | 300 |
| 装甲 | 金 | 4 格血 | 400 |

闪烁红色的敌方坦克被击毁后会掉落道具：★ 升级（火力/双发/破钢）、⛑ 护盾、💣 清屏、🚹 加命、🪏 钢墙、⏱ 冻结。

## 运行

直接用浏览器打开 `index.html` 即可，无需服务器、无需安装。

也可用本地服务器：
```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 特性

- 复古像素风，CRT 扫描线滤镜，Press Start 2P 字体
- 13×13 网格战场，砖墙四分之一格精细破坏
- 4 种敌方 AI，贪心寻路 + 随机扰动
- 6 种道具系统
- 4 个手工关卡，关卡间进度延续
- localStorage 记录最高分
- 桌面/移动端自适应，移动端虚拟按键
- Web Audio API 合成音效，无外部音频文件
- 60FPS 固定时间步长游戏循环

## 技术栈

原生 HTML5 + CSS3 + JavaScript (ES6+)，无框架、无构建步骤。全部图形由 Canvas 程序化绘制，单文件 `index.html` 包含所有代码、样式与逻辑。
